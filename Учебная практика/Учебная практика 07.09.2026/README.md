# Учебная практика 07.09.2026

В работе спроектирована база данных для хранения партнеров, товаров и
истории отгрузок. Используется PostgreSQL 16.

## Требования

- PostgreSQL 16+
- консольные программы `createdb` и `psql`

```text
    └── queries.sql
```

## Схема базы данных

В базе используются три таблицы:

- `partners` - основные и контактные данные партнеров;
- `products` - справочник товаров;
- `sales` - история отгрузок с указанием партнера и товара.

Схема приведена к 3NF: сведения о партнерах и товарах вынесены в отдельные
таблицы, а в истории отгрузок хранятся только ссылки на них и данные конкретной
операции. Итоговая сумма не хранится отдельно, а рассчитывается в запросах из
количества и цены за единицу.

Ограничения целостности:

- каждая таблица имеет первичный ключ;
- `sales.partner_id` и `sales.product_id` являются внешними ключами;
- ИНН и электронная почта партнера уникальны;
- обязательные поля имеют ограничение `NOT NULL`;
- рейтинг, количество и цены проверяются ограничениями `CHECK`;
- удаление партнера или товара с существующими продажами запрещено через
  `ON DELETE RESTRICT`.

## Очистка исходных данных

Перед импортом были выполнены следующие действия:

- удалены пробелы в начале и конце названий компаний;
- дата `15.03.2026` приведена к формату `2026-03-15`;
- пустые телефон и рейтинг оставлены пустыми и импортируются как `NULL`;
- проверены идентификаторы и дубликаты строк;
- продажа `sale_id=104` исключена из очищенного файла, потому что партнера с
  `partner_id=4` нет в исходном списке.

После очистки должны импортироваться 3 партнера, 3 товара и 4 продажи.

## Полный цикл запуска

Все команды выполняются из папки `Учебная практика 07.09.2026/`.

```bash
# 1. Создание базы данных
createdb practice_db

# 2. Создание таблиц
psql -d practice_db -f "Написание DDL-скрипта (База данных в коде)/schema.sql"

# 3. Импорт очищенных данных
cd "Подготовка данных и импорт (ETL)"
psql -d practice_db -f import_data.sql

# 4. Проверка количества и качества загруженных строк
psql -d practice_db -f verification_queries.sql

# 5. Запуск запросов, эмулирующих работу приложения
psql -d practice_db -f "../Разработка проверочных SQL-запросов (Эмуляция бэкенда)/queries.sql"
```

При повторном запуске `schema.sql` таблицы удаляются и создаются заново.
