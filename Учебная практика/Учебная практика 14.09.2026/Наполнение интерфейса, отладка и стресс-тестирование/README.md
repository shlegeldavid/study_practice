# Список партнеров

Финальная версия учебного приложения на Python, Tkinter и SQLite.
Программа получает партнеров из базы данных, показывает их контакты и
автоматически рассчитывает скидку по общей истории продаж.

Партнер без продаж также выводится в списке. Для него количество считается
равным нулю, а скидка отображается как `0%`.

## Запуск приложения

Дополнительные библиотеки не нужны. В этой папке выполнить:

```text
python app.py
```

При первом запуске будет создан файл `partners.db` с демонстрационными
данными. Партнер «Север» специально добавлен без истории продаж.
Кнопка «Обновить список» повторно читает актуальные данные из базы.

## Проверка

Запуск автоматических тестов:

```text
python -m unittest discover -s . -p "test_*.py"
```

Финальный демонстрационный тест создает во временной базе 1000 партнеров,
получает их одним запросом и проверяет рассчитанные скидки:

```text
python demo_test.py
```
