# Учебная практика 14.09.2026

Все команды запускаются из директории `Учебная практика 14.09.2026/`.

Проект представляет собой небольшое настольное приложение для просмотра
партнеров. Данные хранятся в SQLite, а скидка рассчитывается автоматически
по общему количеству проданного товара.

## Требования

- Python 3.10+
- Tkinter
- SQLite 3

Tkinter и SQLite входят в стандартную поставку Python, поэтому установка
дополнительных пакетов не требуется.

## Полный цикл запуска

Все команды выполняются из директории `Учебная практика 14.09.2026/`.

### 1. Проверка расчета скидки

```bash
python -m unittest discover -s "Разработка ядра бизнес-логики (Расчет скидки)" -p "test_*.py" -v
```

### 2. Проверка интеграции с базой данных

```bash
python -m unittest discover -s "Интеграция с БД и агрегация данных (SQL + Backend)" -p "test_*.py" -v
```

### 3. Проверка финальной версии

```bash
python -m unittest discover -s "Наполнение интерфейса, отладка и стресс-тестирование" -p "test_*.py" -v
```

### 4. Демонстрационный и нагрузочный тест

```bash
python "Наполнение интерфейса, отладка и стресс-тестирование/demo_test.py"
```

Тест создает во временной базе 1000 партнеров, получает их одним запросом и
проверяет, что для всех записей рассчитана допустимая скидка. Первый партнер
специально не имеет истории продаж и должен получить скидку `0%`.

### 5. Запуск приложения

```bash
python "Наполнение интерфейса, отладка и стресс-тестирование/app.py"
```

После запуска откроется окно со списком партнеров, контактами, рейтингом и
процентом скидки. Кнопка «Обновить список» повторно загружает актуальные
данные из файла `partners.db`.

Демонстрационные данные финального приложения:

| Партнер | Объем, шт. | Скидка |
| --- | ---: | ---: |
| ООО «Вектор» | 50 000 | 10% |
| АО «Маяк» | 300 000 | 15% |
| ООО «Ромашка» | 10 000 | 5% |
| ИП «Север» | 0 | 0% |

## Логика расчета скидки

| Общий объем продаж | Скидка |
| --- | ---: |
| Менее 10 000 | 0% |
| От 10 000 до 49 999 | 5% |
| От 50 000 до 299 999 | 10% |
| 300 000 и более | 15% |

Суммарное количество товара рассчитывается запросом с `LEFT JOIN` и
`COALESCE(SUM(quantity), 0)`. Поэтому партнер остается в списке даже при
полном отсутствии продаж, а значение `NULL` заменяется на `0`. В этом случае
скидка равна `0%`, и приложение продолжает работать без ошибки.
