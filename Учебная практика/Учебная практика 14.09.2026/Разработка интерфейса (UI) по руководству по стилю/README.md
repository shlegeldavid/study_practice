# Интерфейс для просмотра партнеров

Учебное приложение на Python и Tkinter. На главной форме
отображаются логотип компании, заголовок и карточки партнеров.

## Запуск

Дополнительные библиотеки не нужны. Достаточно Python 3 с Tkinter.

```text
python app.py
```

Изображения для шапки и иконки окна хранятся в папке `resources`.
