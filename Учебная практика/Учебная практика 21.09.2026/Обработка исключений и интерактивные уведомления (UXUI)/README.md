# Проверка ввода и уведомления

Самостоятельная версия приложения на Python, Tkinter и SQLite. Все файлы
для запуска находятся в этой папке.

## Запуск

Нужен Python 3.10+ с Tkinter. Из этой папки выполните:

```text
python app.py
```

При первом запуске создается `partners.db` с демонстрационными данными.
Нового партнера можно добавить через кнопку на главной форме, существующего
открыть кнопкой «Редактировать» на его карточке.

## Сообщения пользователю

- Ошибка с пиктограммой крестика появляется, если наименование или email
  пустые, тип не выбран, рейтинг не является целым неотрицательным числом
  или возникла проблема с базой. В сообщении указано, что исправить.
- Предупреждение с восклицательным знаком появляется при закрытии карточки
  с несохраненными изменениями через «Назад» или крестик окна. Можно
  остаться в форме или подтвердить потерю введенных данных.
- Информация с пиктограммой `i` подтверждает успешное добавление или
  сохранение изменений после записи в базу.

Если нужно продолжить работу со старой базой, до первого запуска скопируйте
ее `partners.db` в эту папку. Приложение добавит недостающие поля адреса и
email в копию, сохранив партнеров и историю продаж.

## Проверка

```text
python -m unittest discover -s . -p "test_*.py" -v
```

Тесты проверяют валидацию ввода, сохранение партнеров, обновление старой
схемы и сохранность связей с историей продаж.
