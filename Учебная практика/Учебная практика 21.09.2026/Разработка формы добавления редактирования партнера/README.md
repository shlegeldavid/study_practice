# Форма партнера

Самостоятельная версия приложения на Python, Tkinter и SQLite. Код списка
партнеров, работы с базой и расчета скидки находится в этой папке.

## Запуск

Нужен Python 3.10+ с Tkinter. Из этой папки выполните:

```text
python app.py
```

При первом запуске создается `partners.db` с демонстрационными данными.
Нажмите «Добавить партнера», чтобы открыть карточку. Кнопка «Назад» или
крестик закрывают ее и возвращают к списку.

## Поля карточки

- Наименование, адрес и ФИО директора — обычные текстовые поля.
- Тип партнера выбирается из списка: ЗАО, ООО, ИП, АО, ПАО. Свой вариант
  напечатать нельзя.
- Рейтинг принимает неотрицательное целое число из цифр `0`–`9`;
  отрицательные и дробные значения ввести нельзя.
- Телефон и email показывают примеры формата прямо в пустых полях. При
  вводе подсказка исчезает, а пустое поле после потери фокуса снова ее
  показывает.

На этом этапе сделан интерфейс карточки. Запись и изменение данных в SQLite
будут добавлены в отдельном задании по CRUD.
