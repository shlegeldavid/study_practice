# Многооконная архитектура и навигация

Продолжение приложения из практики 14.09.2026. Главная форма `MainWindow`
показывает список партнеров и скидок из SQLite. Кнопка «Добавить партнера»
открывает отдельное окно `PartnerEditWindow` с полями карточки партнера.

## Запуск

Нужен Python 3.10+ с Tkinter. В этой папке выполните:

```text
python app.py
```

При первом запуске программа создаст `partners.db` с демонстрационными
данными. Файл базы находится рядом с `app.py`.

## Проверка навигации

1. Убедитесь, что заголовок главного окна — «CRM: Реестр партнеров» и
   партнеры отображаются в списке.
2. Нажмите «Добавить партнера». Откроется окно с заголовком
   «CRM: Карточка партнера [Добавление]».
3. Нажмите «Назад» или закройте карточку крестиком. Карточка закроется,
   а главное окно со списком останется открытым.
4. Повторно откройте карточку и вернитесь назад: переход работает
   несколько раз подряд без создания дополнительных главных окон.

На этом этапе поля карточки показывают структуру формы. Сохранение и
редактирование записей относятся к следующим заданиям практики.
