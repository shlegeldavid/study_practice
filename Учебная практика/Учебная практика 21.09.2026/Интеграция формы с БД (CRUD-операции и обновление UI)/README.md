# Сохранение и редактирование партнеров

Самостоятельная версия приложения на Python, Tkinter и SQLite. Все нужные
файлы находятся в этой папке.

## Запуск

Нужен Python 3.10+ с Tkinter. Из этой папки выполните:

```text
python app.py
```

При первом запуске создается `partners.db` с четырьмя демонстрационными
партнерами. Кнопка «Добавить партнера» открывает пустую карточку. После
заполнения полей нажмите «Сохранить»: запись появится в списке без ручного
обновления. Кнопка «Редактировать» на карточке партнера заново читает его
данные из базы. После сохранения изменения сразу видны в списке.

Поля адреса и email добавляются и в уже существующую базу из предыдущего
этапа. Старые партнеры и их история продаж сохраняются; новые поля у старых
записей сначала пустые. ID партнера при редактировании не меняется, поэтому
записи истории продаж продолжают ссылаться на него. Проверка внешних ключей
в SQLite включена для каждого подключения.

Если нужно продолжить работу с данными прошлого этапа, до первого запуска
скопируйте его файл `partners.db` в эту папку. Приложение обновит схему этой
копии при запуске; исходный файл останется без изменений. Не заменяйте уже
созданную здесь базу, если в ней есть нужные записи.

## Проверка

```text
python -m unittest discover -s . -p "test_*.py" -v
```

Тесты проверяют добавление, изменение, сохранение истории продаж, обновление
старой схемы и запрет продажи для несуществующего партнера.
